Deploy

Put this page on the public web.

This page is fully static, so GitHub Pages can host it for free under your own public link — no server, no hosting bill. Download the files, push them to a repo, and the site is live. About ten minutes, start to finish.

Your files

Two files make up the whole site. index.html is the page itself; signature.png is the signature in the top pill, and it has to sit in a folder named assets in the repo, exactly as it does here.

Download signature.png
01

Create a GitHub account

Go to github.com and sign up — it's free. Skip this step if you already have an account.

02

Create a repository

Click the + at the top right of GitHub, then New repository. Name it yourusername.github.io (with your real username) to get the shortest link, keep it set to Public, and create it.

03

Upload index.html

In the new repo, choose Add file → Upload files, drop in the index.html you downloaded above, and commit the changes.

04

Add the signature

Choose Add file → Create new file and name it assets/keep.txt — that creates the assets folder. Open the folder, then Add file → Upload files and drop in signature.png. You can delete keep.txt afterwards.

05

Turn on Pages

In the repo, open Settings → Pages. Under “Build and deployment”, pick Deploy from a branch, choose the main branch and the / (root) folder, then Save.

06

Open your link

Give it a minute or two, then refresh Settings → Pages — your live address appears at the top: yourusername.github.io. Anyone with the link can now see this page.

Updating the site later Come back here, download a fresh index.html, and upload it over the old one in the repo (same Upload files flow). GitHub Pages republishes within a minute or two — nothing else to change.
Custom domain (optional) The github.io link is free forever. If you later want your own domain name instead, buying one runs about $10–15/year; you connect it under Settings → Pages → Custom domain and point the registrar's DNS at GitHub.
